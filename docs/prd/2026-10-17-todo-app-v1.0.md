## 1. 背景与目标

- 业务背景：个人事务管理场景高频且分散，缺一个轻量工具集中记录与追踪；
- 要解决的问题：待办事项记不住、漏办、无优先级；
- 成功指标：从打开应用到完成一次任务创建 ≤ 3 步操作、≤ 10 秒。

## 2. 目标用户与使用场景

- 目标用户：需要日常事务管理的个人用户；
- 核心场景：
  1. 作为用户，我希望快速记录待办事项，以便不漏办；
  2. 作为用户，我希望标记完成与查看历史，以便掌握进度；
  3. 作为用户，我希望按状态筛选，以便聚焦未完成事项。

## 3. 功能清单

| 编号 | 功能 | 描述 | 优先级 | 关联验收标准 |
|---|---|---|---|---|
| F-01 | 用户注册登录 | 用户名 + 密码，JWT 认证 | P0 | AC-01、AC-02 |
| F-02 | 创建任务 | 输入标题创建未完成任务 | P0 | AC-03、AC-04 |
| F-03 | 任务列表 | 分页展示，支持按状态筛选 | P0 | AC-05 |
| F-04 | 完成任务 | 切换完成 / 未完成状态 | P0 | AC-06 |
| F-05 | 删除任务 | 软删除单条任务 | P1 | AC-07 |
| F-06 | 截止时间 | 创建时可选设置 dueAt | P2 | AC-08 |

## 4. 交互说明

- 关键流程：
  1. 注册 / 登录：未登录访问任务页跳转登录页；登录成功返回任务页；
  2. 创建任务：输入标题（≤200 字符）→ 回车或点击添加 → 列表即时出现，输入框清空；
  3. 筛选：全部 / 未完成 / 完成 三个 tab，切换即时刷新；
  4. 完成：点击 checkbox 切换状态，列表样式即时反馈；
  5. 删除：点击删除，即时移除。
- 页面要点：空列表显示引导文案；加载中显示骨架；网络失败显示错误态 + 重试。

## 5. 非功能需求

- 性能：列表接口 P95 ≤ 300ms；首屏 ≤ 2s；
- 安全：密码 BCrypt 存储；接口除登录注册外均需 JWT；越权访问返回 403；
- 兼容性：Chrome / Safari / Edge 最新两个大版本；移动端 375px 起；
- 可用性：所有操作有反馈；失败可重试。

## 6. 验收标准

| 编号 | Given | When | Then |
|---|---|---|---|
| AC-01 | 用户未注册 | 用合法用户名 + ≥8 位密码注册 | 注册成功返回 token，可进入任务页 |
| AC-02 | 用户已注册 | 用错误密码登录 | 返回 401，提示"用户名或密码错误" |
| AC-03 | 用户已登录 | 输入"买牛奶"并添加 | 列表出现该任务，状态未完成，输入框清空 |
| AC-04 | 用户已登录 | 标题为空点击添加 | 不创建任务，提示"任务内容不能为空" |
| AC-05 | 用户有 25 条任务 | 请求第 2 页（pageSize=20） | 返回 5 条，total=25 |
| AC-06 | 任务为未完成 | 点击其 checkbox | 任务变为已完成，列表样式更新 |
| AC-07 | 用户有 1 条任务 | 点击删除 | 列表移除该任务，刷新后不再出现 |
| AC-08 | 用户已登录 | 创建任务时设置截止时间 | 任务详情包含 dueAt 且与输入一致 |

## 7. 风险与依赖

- 外部依赖：无第三方服务；
- 风险：登录态过期处理（前端跳转登录并保留已填内容）。
