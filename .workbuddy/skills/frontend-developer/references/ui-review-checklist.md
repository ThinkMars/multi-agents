# UI 走查清单

前端自测与测试角色走查共用。分「通用」与「按栈专项」两节，逐项检查并记录结果。

## 通用项（所有栈）

### 布局与响应式

- [ ] 目标分辨率下无溢出、无横向滚动条
- [ ] 断点行为正确（窄屏堆叠 / 宽屏分栏）
- [ ] 固定定位元素不遮挡关键操作
- [ ] 安全区适配（刘海 / 底部横条，移动端）

### 视觉

- [ ] 主题色 / 字体走统一变量，无散落硬编码
- [ ] 文字对比度满足 WCAG AA
- [ ] 深浅色模式（如支持）下均正常
- [ ] 图标清晰、尺寸统一、对齐一致

### 交互与反馈

- [ ] 所有可点击区域有 hover / active / disabled 态
- [ ] 操作后有明确反馈（toast / 状态变化 / 跳转）
- [ ] 防重复提交（按钮 loading + 禁用）
- [ ] 表单错误即时提示，错误信息可读

### 状态完备性

- [ ] 加载态：骨架屏 / loading，无白屏
- [ ] 空态：引导文案 + 主操作
- [ ] 错误态：可读信息 + 重试入口
- [ ] 边界：超长文本、极端数量、慢网络降级

### 兼容性

- [ ] 目标浏览器 / 系统版本矩阵内渲染一致
- [ ] 低版本降级方案生效（不白屏）
- [ ] 横竖屏 / 窗口缩放（桌面端）布局不破

## React 专项

- [ ] 控制台无 error / warning（含 key、act 警告）
- [ ] 路由懒加载生效，首屏 JS 体积合理
- [ ] useEffect 清理函数完备，无内存泄漏（反复进出页面）

## Vue 专项

- [ ] 控制台无 error / warning
- [ ] v-for key 使用稳定 ID
- [ ] scoped 样式无意外污染

## Flutter 专项

- [ ] 双端渲染一致（像素级对齐处重点核对）
- [ ] 键盘弹出不遮挡输入框
- [ ] 长列表滚动流畅，无掉帧
- [ ] 深浅色主题均正常

## Electron 专项

- [ ] 窗口缩放 / 最大化布局正常
- [ ] 主进程崩溃有恢复策略
- [ ] 生产包 CSP 生效，无 remote 调试端口

## 小程序专项

- [ ] setData 只传变化字段，无全量刷新热点
- [ ] 主包体积 < 2M，分包生效
- [ ] 触底加载 / 分页正常
- [ ] 网络失败有空态与重试
- [ ] 审核要求项（隐私协议、类目资质）已配置
