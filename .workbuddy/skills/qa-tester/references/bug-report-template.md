## 严重级定义

| 级别 | 定义 |
|---|---|
| 致命 | 核心流程不可用 / 数据丢失 / 安全问题 |
| 严重 | 主要功能错误且无规避方案 |
| 一般 | 功能错误但有规避方案，或非核心功能错误 |
| 轻微 | UI / 文案 / 体验问题，不影响功能 |

## 状态流转

新建 → 已确认 → 修复中 → 待回归 → 已关闭（或非缺陷）
回归未通过时打回「修复中」并在单内追加记录。
