## 3. 测试策略

- 功能测试：基于 C2 验收标准逐条转用例；
- 接口测试：基于 C3 的状态码、错误码、分页结构；
- 数据测试：基于 C4 的约束、默认值、级联行为；
- 兼容 / 性能 / 安全：按 `qa-checklists.md` 裁剪。
