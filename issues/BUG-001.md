# BUG-001 空标题创建任务返回 500 而非 400

| 项 | 内容 |
|---|---|
| 缺陷编号 | BUG-001 |
| 严重级 | 严重 |
| 优先级 | P0 |
| 发现迭代 / 日期 | Sprint 1 / 2026-10-17 |
| 报告人 | 测试角色 |
| 当前状态 | 修复中 |

## 环境

- 端 / 浏览器 / 系统版本：Chrome 141 / macOS 15；
- 账号角色：已登录普通用户；
- 关联契约：C1 v1.0（AC-04）/ C3 v1.0（POST /tasks 400 响应）/ C4 v1.0。

## 复现步骤

1. 使用已登录账号，请求 `POST /api/v1/tasks`；
2. 请求体为 `{"title": ""}`；
3. 观察响应。

## 期望结果

依据 C3：返回 400，错误码 40001，message 为"任务内容不能为空"，不创建任务（AC-04）。

## 实际结果

返回 500，错误码 50000，message 为"服务器内部错误"；数据库中未创建记录。

## 影响分析

前端无法按契约映射错误提示（会把用户导向"服务故障"重试路径），违反 C3 约定；有规避方案（前端先做非空校验），但契约一致性被破坏，需修复。

## 附件

- 抓包：`title` 为空字符串时，service 层直接落库触发数据库 NOT NULL 前的长度校验缺失。

## 处理记录

- 2026-10-17 后端角色确认：controller 层缺少 `@NotBlank` 校验，补校验后回归 TC-005 / TC-006。
