# 六类测试清单

用例设计时按类型逐项过，避免只测 happy path。

## 1. 功能测试

- [ ] 每个 P0 功能的 AC 有用例覆盖（含正常路径）
- [ ] CRUD 全链路：创建 → 查询 → 更新 → 删除 → 复现
- [ ] 状态流转正确（如任务 未完成 → 已完成 → 未完成）
- [ ] 权限边界：不同角色看到 / 操作到的数据符合预期
- [ ] 分页 / 排序 / 过滤参数生效
- [ ] 重复操作（连点、刷新后重提）结果正确

## 2. 边界测试

- [ ] 输入为空 / 空格 / 纯符号
- [ ] 超长输入（超出 C3 maxLength）
- [ ] 数值边界：0、负数、最大值 + 1
- [ ] 时间边界：跨天、跨时区、历史时间、未来时间
- [ ] 数量边界：空列表、单条、分页临界（pageSize=1 / 100 / 101）
- [ ] 并发边界：同用户双端同时操作同一资源

## 3. 异常测试

- [ ] 网络中断 / 超时 / 5xx，界面有错误态与重试
- [ ] 后端返回 400/401/403/404/409/422，错误码映射正确
- [ ] token 过期，跳转登录且不丢用户已填内容
- [ ] 后端契约字段缺失或类型不符，前端不白屏
- [ ] 数据库写入失败（违反唯一约束）返回 409 而非 500

## 4. 兼容测试

- [ ] 目标浏览器 / 系统版本矩阵内渲染一致
- [ ] 低版本降级生效（不白屏、核心流程可用）
- [ ] 不同屏幕尺寸 / DPI 无溢出错位
- [ ] 横竖屏 / 窗口缩放（桌面端）布局不破

## 5. 性能测试

- [ ] 首屏时间符合 C1 非功能需求基线
- [ ] 列表页 100 条数据滚动流畅（移动端重点）
- [ ] 高频交互（输入、切换 tab）无卡顿
- [ ] 接口响应时间在基线内（P95）
- [ ] 无重复请求 / 内存持续增长（反复进出页面）

## 6. 安全测试

- [ ] 未登录访问受保护接口返回 401
- [ ] 越权访问他人资源返回 403 / 404
- [ ] 注入类输入（SQL 片段、脚本、超长 payload）被正确处理
- [ ] 敏感信息（token、密码、手机号）不落日志、不明文返回
- [ ] 文件上传类型 / 大小受限（如适用）
